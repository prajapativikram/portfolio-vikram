# Vikram Kumar Portfolio (Expanded Edition)

Static HTML, CSS, and JavaScript portfolio with responsive design, light/dark mode, project filtering, internship experience, achievements, education, contact links, and a downloadable resume.

## Start
Open `index.html` directly, or use VS Code Live Server. No dependencies or build step.

## Customization and verification
- Project descriptions reflect prior discussions and resume material. Some projects are prototypes, concepts, or learning exercises, not verified production applications.
- Add individual GitHub repository and live-demo links only after confirming their URLs.
- Verify participation, internship dates, and certificate details before public deployment.
- Replace the resume in `assets/` when you update it.
- Contact form uses `mailto:` and requires the visitor's configured email application.

## Deploy
Upload the folder to GitHub Pages, Netlify, or Vercel as a static website.
