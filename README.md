## Getting Started

### Prerequisites

You only need:

- A modern web browser
- VS Code or another code editor
- Git (optional)

No Node.js installation, package manager, or build process is required.

### 1. Clone the Repository

```bash
git clone https://github.com/prajapativikram/portfolio-vikram.git
```

### 2. Navigate to the Project Directory

```bash
cd portfolio-vikram
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the Website

Open `index.html` directly in your browser.

Alternatively, use the **Live Server** extension in VS Code:

1. Install Live Server.
2. Open the project folder.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website will launch in your default browser.

## GitHub Pages Deployment

This portfolio is hosted using GitHub Pages.

### Deployment Steps

1. Push the source code to a GitHub repository.
2. Open the repository on GitHub.
3. Navigate to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch.
6. Choose the `/(root)` directory.
7. Click **Save**.
8. Wait for the deployment workflow to complete.

The website will become available at:

**https://prajapativikram.github.io/portfolio-vikram/**

### Deployment Configuration

| Setting | Value |
|---------|-------|
| Hosting Platform | GitHub Pages |
| Source | Deploy from a branch |
| Branch | main |
| Directory | /(root) |
| HTTPS | Enabled |
| Build Command | Not required |
